# World reconciliation and measurable feedback

**THE WORLD CORRECTS THE DRAGON.** Internal agreement, changed prose and lower entropy do not establish correctness. External evidence and eventual observed outcomes constrain the system.

```text
WORLD -> HYDRA -> MEDUSA -> TEMPORAL MEMORY -> FEATURES -> MATH
-> MODELS -> SIMULATION -> TRIBUNAL -> UNCERTAINTY -> QWEN / CODEX
-> HYPOTHESIS / ACTION -> RESEARCH NEED -> HYDRA -> WORLD
-> NEW EVIDENCE -> RECONCILIATION -> LEARNING FEEDBACK -> NEXT CYCLE
```

This is the architectural target. The parent foundation represents the cognitive boundary and its records; it does not claim every downstream parent stage is implemented. Existing mathematical and validation components keep their roles, and CHILD experiments are not imported to fill gaps.

## One replayable cycle

1. Freeze a sanitized state at its explicit as-of cursor; identify inputs and hashes.
2. Compare against a prior compatible snapshot and retain evidence/model/uncertainty deltas.
3. Record each actor's typed position and reconcile agreement, disagreement or incomparable inputs.
4. Validate a bounded proposal against available capabilities and source/temporal policy.
5. Record the decision, actual action result, cost/latency and newly accepted evidence references.
6. Recalculate only through the existing evidence/calculation boundaries; retain the original forecast.
7. When later evidence or an outcome exists, append measured feedback and link the next cycle.

The original prospective prediction remains immutable. A later calculation is a separate version with its own time, inputs and hash. Outcome scoring requires actual observed evidence available after the original prediction; a future projection cannot satisfy that gate.

## LearningFeedback

The record supports prediction before/after, eventual actual outcome, model errors/calibration, research action, new evidence, uncertainty before/after, cost and latency, whether the prediction changed, and whether a source, Qwen proposal or Codex proposal proved useful. Both AI positions may be wrong. Missing outcome or comparison evidence yields UNKNOWN/INSUFFICIENT_EVIDENCE rather than an accuracy gain.

The foundation implements before/after distributions, validated observed outcome, multiclass Brier errors/gain, uncertainty, cost/latency, referenced usefulness indicators and traced cohort calibration arithmetic. Brier claims require matching fixture and frozen forecast clocks before the observed event. Calibration comparison requires identical cohort/protocol and exact binned ECE difference. Population generalization, causal usefulness attribution and automatic weight/source-policy updates remain unproved follow-through work. The exact fields and invariants are in [data contracts](COGNITIVE_DATA_CONTRACTS.md).

Uncertainty reduction can be measured before an outcome arrives, but it is not automatically an accuracy or calibration improvement. Accuracy gain needs an observed outcome and a declared scoring/comparison method. Calibration needs an adequate declared scored sample, not one forecast. Attribution of improvement to a research action needs a suitable comparison; correlation alone is not causal proof.

Learning need not retrain neural weights. Future bounded adaptations may update prior-score model weights, source reliability, feature usefulness, research strategy, action usefulness, uncertainty prioritization or acquisition strategy. Every change must state its prior value, new value, evidence, method/version, temporal eligibility and measurable evaluation. The foundation does not silently apply policy or model changes from AI prose.
