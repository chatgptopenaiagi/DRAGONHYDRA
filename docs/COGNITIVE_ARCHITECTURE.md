# Cognitive architecture foundation

**Scoped foundation: COMPLETE. Operational cognition: PARTIAL / EXPERIMENTAL.** The owner-authorized block adds a cognitive coordination boundary above the existing parent system. It does not promote the CHILD experiment into the parent, complete V2–V10, establish consciousness, or demonstrate predictive improvement. Current verification and limits are in [cognitive progress](COGNITIVE_PROGRESS.md).

## Operational awareness

AWARENESS means a continuously reconstructable structured representation of the current system, temporal cursor, active fixture/context, validated evidence and changes, missing evidence, model outputs and disagreement, simulation state, uncertainty, source health and failures, research needs, previous actions/results, system health, permitted capabilities, goals and unresolved questions. Missing components remain explicit; empty or unavailable data is not successful analysis.

The deterministic builder consumes controlled project state and emits a bounded sanitized snapshot. Neither AI receives an unrestricted SQL administrator connection. The snapshot preserves source/provenance references, input hashes, state hash, as-of time, temporal mode and epistemic labels. Identical controlled input and timestamps produce identical content and hash. Later evidence produces a new state and delta; earlier snapshots remain immutable.

The initial live parent projection uses the existing SQL read role, a fixed parameterized as-of query, stable ordering and a 32-record ceiling. It describes accepted captured source records, not verified exact match kickoff/final-whistle times. It is a bounded sample rather than a full database reconstruction. No active fixture is automatically selected. Parent feature, model, Tribunal, simulation, real-market and live source-health views remain explicitly NOT_STARTED when not connected; a stored capture is not live source-health proof.

The cognitive availability bound is conservatively derived as the latest of original source `available_at`, normalization `updated_at` and SQL `created_at`. Original clocks remain represented in content/provenance hashes; `DERIVED_KNOWLEDGE_BOUND` exposes this projection choice. The bound never backdates normalized knowledge to the earlier source capture. The original stored records and databases are unchanged.

```text
Controlled memory / validated state
  -> deterministic sanitized snapshot + state delta
  -> Qwen resident analysis / explicit Codex artifact handoff
  -> typed conclusions and bounded proposals
  -> reconciliation and capability decision
  -> permitted research or calculation request
  -> action result and cognitive cycle receipt
```

## Temporal continuity and disagreement

PAST contains observations, outcomes, revisions and historical evidence. PRESENT is the active as-of cursor and the knowledge available there. FUTURE contains probability distributions, hypotheses and conditional scenarios. Keep STRICT_PIT, RECONSTRUCTED_PIT, HYPOTHESIS, PREDICTION, SIMULATION, OBSERVATION and SYNTHETIC distinct. Capturing an AI prediction now does not make its future subject an observed fact.

Reconciliation preserves each actor's position and state/input references. It can represent AGREEMENT, PARTIAL_AGREEMENT, DISAGREEMENT, INSUFFICIENT_EVIDENCE or NOT_COMPARABLE. Claims about different fixtures, times or incomparable metrics must not be averaged. Measurable model sensitivity may help evaluate competing uncertainty priorities without deciding that either AI statement is evidence.
